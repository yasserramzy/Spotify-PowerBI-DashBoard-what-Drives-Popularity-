# 📊 Spotify Tracks Analysis — What Drives Song Popularity?

## 📌 Project Overview
This project analyzes Spotify track data to uncover the key factors that influence song popularity.
Using Power BI, the analysis explores trends, artist performance, collaboration impact, and relationships between audio features and popularity.

## 🎯 Objectives
- Understand how song popularity is distributed  
- Identify top-performing artists  
- Analyze the impact of collaborations  
- Discover which audio features influence popularity  
- Examine how music trends have evolved over time  

## 📌 Key Skills Demonstrated

- Data Cleaning & Transformation  
- Exploratory Data Analysis  
- Data Visualization (Power BI)  
- Business Insight Generation  
- Dashboard Design & Storytelling  

## 🛠 Tools Used
- Power BI  
- Data Cleaning & Transformation  
- Data Visualization  
- Basic Data Analysis  


## 📈 Key Insights

- Most songs have low popularity, indicating a **hit-driven platform**  
- Solo tracks dominate both in volume and average performance  
- **Danceability and energy** positively influence popularity  
- **Acoustic songs** tend to have lower popularity  
- **Tempo has little to no impact** on popularity  
- Song popularity has increased over time  


## 📊 Dashboard Features

- KPI overview (total tracks, average popularity, max popularity)  
- Top artists based on average popularity  
- Comparison between solo and collaboration tracks  
- Popularity distribution (histogram)  
- Trend analysis over time  
- Feature impact analysis using scatter plots

## 💡 Conclusion

This analysis highlights that song popularity is influenced by a combination of audio features and market dynamics. 
While most songs achieve low popularity, a small percentage become highly successful, indicating a competitive and hit-driven industry.
